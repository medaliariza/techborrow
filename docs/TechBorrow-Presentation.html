Project overview

TechBorrow organizes equipment inventory, requests, approvals, releases, returns, and maintenance in one web application with an Android web-view installer.

Goal: make equipment borrowing visible and accountable for students, instructors, and administrators.

Users and workflow

  • Students submit a public request with identity details and a consented photo.
  • Instructors sign in, browse equipment, and submit requests.
  • Admins manage inventory, review requests, release equipment, inspect returns, and track maintenance.

Technology and deliverables

  • PHP 8, MySQL, Bootstrap, session-based role access.
  • Progressive web application features and Android APK (minimum Android 6.0 / API 23).
  • PHP form endpoints are documented in the included Postman collection; they return HTML/redirects rather than JSON.
